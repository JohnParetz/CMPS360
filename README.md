
# CMPS360

This repository has Module 1 and lab.

## Lab - Hello World

Created a simple Java program to test my Java setup in VS Code and practice compiling and running Java code.

## Assignment 1 - Student Grade Calculator

Created a program that stores student information and calculates the average of three assignment grades.

The program also determines the letter grade and whether the student passed or failed using if/else statements.

## Assignment 2 - Bookstore Inventory

Created a bookstore inventory application using two Java classes: Product and InventoryApp.

The program displays book information, calculates inventory values, and checks if books need to be restocked.

## How to Run the Programs

### Requirements
- Java JDK 25
- Visual Studio Code
- Java Extension Pack for VS Code

### Steps

1. Download or clone this repository from GitHub.
2. Open the CMPS360 folder in VS Code.
3. Open a new terminal using **Terminal > New Terminal**.
4. Make sure the terminal is in the main CMPS360 folder.
5. Use the commands below to compile and run each program.

### Lab - Hello World

Compile:
```
javac Lab\HelloWorld.java
```

Run:
```
java Lab.HelloWorld
```

### Assignment 1 - Student Grade Calculator

Compile:
```
javac Assignment1\StudentGradeCalculator.java
```

Run:
```
java Assignment1.StudentGradeCalculator
```

### Assignment 2 - Bookstore Inventory

Compile:
```
javac Assignment2\Product.java Assignment2\InventoryApp.java
```

Run:
```
java Assignment2.InventoryApp
```

### Notes

- `javac` compiles the Java source code (.java) into bytecode (.class).
- `java` runs the compiled program using the Java Virtual Machine (JVM).
- If changes are made to the code, compile it again before running.
